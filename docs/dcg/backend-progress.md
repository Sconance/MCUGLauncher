# 后端任务进度

更新日期为 2026-11-26。记录基于 `tauri-feat/下载和启动` 的本地提交 `9385798` 及当前工作区的加载器和整合包改动。

## 已接通的桌面端功能

| 功能 | 当前进度 |
| --- | --- |
| 设置与实例目录 | 按平台初始化配置，持久保存多个游戏根目录。支持系统目录选择器、当前目录和全部登记目录的实例扫描、移除目录登记。移除登记只修改配置。 |
| 原版与加载器安装 | 从 Mojang 或 BMCLAPI 获取原版版本清单，下载并校验客户端、库和资源。从官方 Maven 获取 NeoForge 兼容版本，Forge 和 NeoForge 使用官方无界面安装器。Fabric 与 Quilt 使用官方 Meta API 的继承配置和 Maven 依赖。安装完成后刷新实例清单。 |
| 离线启动与 Java | 原版、NeoForge、Forge、Fabric 和 Quilt 共用启动流程。带加载器的版本按 `inheritsFrom` 合并依赖和参数。已修复 NeoForge 21.4.161 加载原版与补丁客户端时的重复模块闪退。可扫描并选择本机 Java。Java 安装已实现为 Rust 函数，由调用方显式发起。 |
| 模组搜索与下载 | 默认搜索 Modrinth，按需查询版本和文件。支持将校验过大小和 SHA-1 的 JAR 下载到指定目录。MC 百科保留为可选来源，CurseForge 查询需要配置 API 密钥。 |
| Modrinth 整合包 | Rust 端可预览并安装本地 `.mrpack`，通过压缩包清单下载所需文件，安装游戏和加载器后登记独立游戏目录。 |
| 任务与游戏会话 | 已接入安装、下载和启动任务。支持查询进度和任务结果、按阶段取消及停止游戏。任务随桌面进程保存在内存中。游戏进程输出在配置目录下的 `game-logs/`。 |

## 待接通

- **加载器与登录。** OptiFine、LiteLoader 等加载器的安装和启动，Minecraft 1.20.1 的旧版 NeoForge 安装，在线账号认证和直连服务器启动。
- **实例与模组管理。** 将下载的模组直接安装到目标实例，读取并管理磁盘上的实例模组，实际执行实例卸载、克隆和导出。
- **维护功能。** 整合包页面入口、其他整合包格式、整合包可选文件选择、内容更新、存档备份与恢复，以及任务重启恢复。
