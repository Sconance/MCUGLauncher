# 资源、加载器、拖入及完成后关闭

## 交互

- 资源卡片标题、图片和空白区域可打开详情，原下载按钮保留；收藏按钮不触发详情。五类资源使用同一入口。
- 模组/整合包筛选显示“全部加载器”，请求仍用空字符串表达不限；资源包/光影/数据包不增加加载器筛选。
- 加载器弹窗自动读取，切换后刷新，支持手动重试；用 requestId 和递增版本防止旧结果覆盖新选择。无兼容版本和失败显示明确原因。
- 主窗口注册文件拖入，悬停显示提示；先预览再确认。整合包先确认名称/目录，其他文件确认已选实例；安装和复制由原 App/Core 队列完成。

支持 jar、可识别的 ZIP 和 mrpack：模组、资源包、光影、存档、受支持整合包。数据包必须放入具体存档，本轮明确提示而不猜测路径。没有选择实例、格式不支持或目标运行中会提示。

## 关闭语义

账号登录等待最终 authResult（pending 不关闭，失败保留）；离线改名等待 settingsSaved；实例参数等待 launchOptionsSaved；加载器/资源/导入等待相应入队回执；公告与推荐等待保存成功；更新确认等待入队，卸载二次确认取消时保留原窗口。设置页面本身不关闭，阅读/预览弹窗也不会因为无关状态变化关闭。

成功入队不表示安装已经完成，后续执行状态由下载任务页展示。所有数据校验失败保留输入；登录密码发送后仍按原策略清空。

## 结构与验证

FileDropView 只做原生手势和确认，LocalImportCommands 预览/入队，DownloadExecutor 复用 Core LocalImportClassifier、ContentService.ImportFiles、WorldArchives.Import。来源哈希、真实目录快照和执行占用检查保持在后端。

NativeUiChecks 使用真实鼠标事件验证五类卡片、成功入队关闭、失败登录保留/成功登录关闭、启动选项保存关闭，以及拖入确认交互。WebBridgeChecks 验证本地事务复制、原目标冻结、同名文件保留和预览后文件变动拒绝；QueueChecks 检查既有任务暂停/取消/恢复。

测试使用本地文件与模拟响应，未做真实 Microsoft/MUA 认证、公网资源下载或 Windows Explorer 实际拖放验收。系统拖放通过 Avalonia DataTransfer 获取本地文件，不在视图内解压或复制。
