# 本地文件导入

拖入窗口、安装与导入页面的“选择本地文件”、实例内容管理的“导入本地文件”共享同一确认流程。文件选择是 Windows 权限不同导致无法拖放时的替代入口。

## 本轮支持范围

- JAR：检查 Fabric、Quilt、Forge、NeoForge 标识，不再仅凭后缀把普通库或安装器当作 Mod。
- ZIP / MRPACK 整合包：复用 PackService，支持 Modrinth 和 MultiMC/Prism，包括包裹目录；确认名称后始终创建新实例。CurseForge、MCBBS 目前明确拒绝，不宣称已经支持。
- ZIP 资源包和光影：识别根部 pack.mcmeta、assets/、shaders/。结构有歧义时先选用途，再检查目标并确认，不静默猜安装目录。
- ZIP 存档：复用 WorldArchives，level.dat 位于根目录或一层文件夹，创建独立存档目录。
- 数据包已能识别，但自动选择具体存档、投影和建筑文件仍未实现，会明确提示。嵌套资源包/光影需要先将内容整理到 ZIP 根部；只有受支持的整合包具有多层包裹目录支持。

## 执行与限制

确认窗口先显示再后台读取内容和哈希。允许换目标实例；后端检查运行/维护占用、加载器类型、同名启用或禁用文件。Mod 的完整游戏版本范围、依赖图、不同文件名但相同 Mod ID 尚未在此入口自动核验，窗口明确提示需核对，不虚报全部兼容。

无歧义文件和用户明确选择用途的文件才生成确认令牌。请求标识隔离异步结果，界面丢弃旧选择的迟到结果。确认后冻结目标及 SHA-256；执行前再次检查来源文件，复制使用既有事务和取消机制。同名文件不覆盖；任务由现有队列持有，页面切换不会取消。复制进度进入同一任务进度；存档按文件显示处理信息。

批量拖入按文件顺序分别确认，可取消当前项后继续下一项。窗口有未处理导入时拒绝新的拖放，避免重叠；成功入队后关闭确认窗，可在右上角任务列表查看实际完成、失败、取消或重试状态。“已入队”不代表“安装完成”。

## 结构

UI 的 FileDropView 仅处理文件手势；LocalImportDialog 仅处理目标/用途选择与确认，调用 Contracts.ILauncherService。App 的 LocalImportCommands 做预览和验证，DownloadExecutor 执行现有队列任务；Core 的 LocalImportClassifier 识别结构，ContentService/WorldArchives/PackService 执行安装。没有新增下载器或把业务写入 ShellWindow。

## 验证范围

LibraryChecks 覆盖普通 JAR、真实模组标识、包裹目录、歧义、危险路径和无关 manifest；WebBridgeChecks 覆盖显式目标、冻结目标、同名冲突、哈希变化、加载器不匹配和歧义选择。NativeUiChecks 覆盖确认、取消、实例选择和原生截图；队列及下载检查覆盖取消/恢复/校验。以上是本地夹具与 headless 控件验证，未代替真实资源管理器拖放、管理员权限差异或真实整合包联网安装验收。

补充验证：已通过确认失败保留窗口/重试关闭、歧义用途选择以及整合包快速识别后切换新实例窗口的原生控件检查；修正了确认窗口尚未挂载时立即关闭的时序问题。
