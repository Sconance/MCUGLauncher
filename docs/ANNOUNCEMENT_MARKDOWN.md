# 公告 Markdown 编写规范

公告 Markdown 文件分为两部分：

1. **预览字段区**：用约定的一级标题声明公告卡片预览使用的标题、正文、配图、标签和作者。
2. **完整公告区**：除预览字段区以外的 Markdown 内容，点击公告预览后交由 Markdown.Avalonia 渲染。

## 预览字段

字段以独占一行的一级标题开头，字段值是该标题之后的内容，直到下一个一级标题或文件结束。标题名区分大小写，必须使用下表中的名称：

| 一级标题 | 用途 | 示例 |
| --- | --- | --- |
| `# preview_title` | 公告预览标题 | `# preview_title` |
| `# preview_body` | 公告预览正文 | `# preview_body` |
| `# preview_pic_url` | 预览配图 URL | `# preview_pic_url` |
| `# tags` | 公告标签 | `# tags` |
| `# author` | 作者 | `# author` |

字段可以按任意顺序出现，也可以缺省。每个字段应只出现一次。字段值前后的空白行不属于字段内容；`preview_body` 可以包含多行文本。`preview_pic_url` 应填写可访问的图片 URL。`tags` 支持以逗号或换行分隔多个标签。

例如：

```markdown
# preview_title
0.22.3 社区功能测试开启

# preview_body
群友推荐、服务器状态与数据源切换开始试运行，欢迎在群里反馈。

# preview_pic_url
https://example.com/images/announcement-cover.jpg

# tags
更新, 社区

# author
TianXuan
```

## 完整公告内容

不属于上述五个预览字段区的内容会保留为完整公告 Markdown，并在用户点击预览后交给 Markdown.Avalonia 渲染。可以使用 Markdown.Avalonia 支持的标题、段落、列表、链接、引用和代码块等格式。

预览字段区是公告元数据，不会作为正文再次显示。普通一级标题不是预览字段；它及其后续内容会保留在完整公告中。例如：

```markdown
# preview_title
社区测试公告

# preview_body
公告卡片中显示的简短介绍。

# 完整公告

这里是点击预览后展示的内容。

## 测试范围

- 群友推荐
- 服务器状态
```

点击预览后，正文从 `# 完整公告` 开始显示；用于生成卡片的 `preview_title` 和 `preview_body` 区块不会显示在完整公告正文中。

## 缺省行为

- 任意预览字段都可以省略。
- 如果五个预览字段全部省略或内容为空，预览正文使用默认文案：**一份很懒的公告**。
- 只有部分字段有内容时，不会触发上述默认文案；未提供的字段留空。
- 缺省预览字段不会影响剩余 Markdown 正文的展示。

## 编写注意事项

- 预览字段标题必须独占一行，并使用单个 `#`；字段名需与表格完全一致。
- 每个预览字段标题只写一次。多个标签请放在同一个 `# tags` 字段中。
- 不要把普通正文写进预览字段区；字段区的内容会被用作预览信息，而不会进入完整公告正文。
- 如果不需要单独的预览内容，可以省略所有预览字段，直接编写公告正文；此时预览正文显示默认文案。
