# 应用内弹窗设计

## 统一结构

DialogWindow 仅负责展示和窗口生命周期：白色标题区、浅色正文、白色固定底栏；边框、文字、按钮状态沿用主界面。关闭按钮在标题栏右上角，弹窗居中于所属窗口，内容过长时只滚动正文。正文宽度受视口约束，长说明自动换行；底部按钮按实际文字测量最小窗口宽度，防止被裁切。

取消在操作组左侧，主要操作在右侧。普通操作白底，主要操作蓝底白字，删除、卸载及强制关闭使用红色明确标识；不把所有正文按钮拉满一行。阅读类弹窗使用“关闭”，错误提示使用“知道了”。Esc 与右上角关闭只关闭当前弹窗，不表示确认提交。

## 各功能安排

| 弹窗 | 正文 | 固定操作 |
| --- | --- | --- |
| 正版账号登录 | 授权说明及账号保存范围 | 取消 / 打开登录窗口 |
| MUA 登录 | 带标签的账号和密码，密码遮盖 | 取消 / 登录 MUA |
| 切换本地账号 | 角色名及离线作用范围 | 取消 / 保存并切换 |
| 选择 MUA 角色 | 角色列表及取消说明 | 取消 / 使用选中角色 |
| 皮肤与披风 | 居中头像、当前账号、支持范围 | 取消 / 恢复默认头像 / 重新读取皮肤 / 选择本地 PNG 皮肤（离线） |
| 服务器 | 名称、地址、格式提示 | 取消 / 添加服务器或保存修改 |
| 整合包导入 | 名称、目录、包信息 | 取消 / 开始导入 |
| 加载器安装 | 基础版本、加载器、兼容版本、状态 | 取消 / 安装所选加载器 |
| 资源详情 | 左侧介绍，右侧兼容版本和目标；手动条件仅在未选择实例时显示 | 取消 / 确认下载 |
| 启动设置 | 可滚动参数表单 | 取消 / 保存设置 |
| 公告及推荐编辑 | 表单与现有条目，说明本地待发布行为 | 取消 / 提交公告或保存本地推荐 |
| 更新与卸载预览 | 具体文件范围及影响 | 取消 / 预览、应用更新或继续卸载 |
| 关闭游戏及删除确认 | 明确不可撤销或未保存进度的影响 | 取消 / 具体操作名 |

MicrosoftLoginWindow 复用外框，授权网页仍由 Microsoft 提供；没有改写官方网页、OAuth 拦截或账号存储逻辑。Windows 文件/目录选择器保留系统原生界面。

## 架构

Ui.Show/Confirm/Error 组装共享窗口；功能视图提供表单和操作。NativePage.DialogActions 只用于展示底栏，PrepareDialog 只移除重复页标题。业务继续经 LauncherFacade 调用已有 App/Core；本轮不修改 App/Core。

## 验证范围

NativeUiChecks 覆盖账号、角色选择取消、服务器、缩小后的皮肤弹窗、滚动启动表单、危险确认、Esc 关闭、资源明确版本提交，以及已有安装入口与公告弹窗检查；保存了对应 Skia 截图并逐张检查。固定底栏、正文宽度与按钮边界均有断言。

系统文件选择器、真实 Microsoft 授权、MUA 在线登录及真实安装未在本轮执行；导入/更新/卸载的界面改动做了代码核对，不把共享外框检查等同于这些真实流程已验收。
