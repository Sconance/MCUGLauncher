# 主页布局约定

本轮按用户要求只调整两处：启动区位于左侧底部，账号卡与启动区之间留白；服务器、公告、推荐、语录共同位于右侧，按内容紧凑排列。

HomePage 的左列使用 Auto / * / Auto 网格，右侧社区卡片不再用星号行撑满高度。展开游戏目录时仍使用原实例选择器，收起后恢复社区卡片；账号切换、快捷设置和运行游戏入口保留。布局调整不改变 Contracts、App、Core 或任何业务调用。

正常高度下启动区跟随窗口底部，短窗口保留最小内容高度并通过现有页面滚动访问，避免账号卡与启动区重叠。社区内容过多时同样可滚动查看。

验证：运行现有 NativeUiChecks，查看 home-small / home-medium 截图；原生控件、主页布局和既有交互检查通过。未修改测试断言或后台业务。
